# Online Exam Portal v1.0

**Release tag:** `v1.0`  
**Release type:** Initial release

The complete list of changes for this release is maintained in
[`CHANGELOG.md`](../../CHANGELOG.md).

## Highlights

- Administrators can create and update examinations.
- Students can view available examinations, start timed attempts, save answers,
  and submit attempts.
- Results are available through the portal after an attempt is evaluated.
- Role-based access separates student and administrator workflows.

## Requirements and setup

- Python 3.11 or 3.12.
- Install the application dependencies from
  `online-exam-portal-skeleton/online-exam-portal/requirements.txt`.
- Apply Django migrations before starting the application.
- SQLite is used by the development configuration. Production database and
  deployment settings are environment-specific.

## Verification

The release CI workflow runs Flake8, Django system checks, migration checks,
and the test suite for the supported Python versions. See the matching GitHub
Actions run for the result associated with the release tag.

## Known limitations

- Production deployment configuration is maintained separately from the
  development settings in this repository.
- This draft describes functionality integrated into `main`; confirm the
  final release scope and known issues with the product owner before
  publication.
