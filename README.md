# Online Exam Portal

## Project Description

The Online Exam Portal is a web-based examination system that allows
students to attend multiple-choice examinations and receive automatically
evaluated results.

The system provides features for examination management, question
management, student examination attempts, automatic evaluation, and
result generation.

## Project Objectives

- Provide an online platform for conducting examinations.
- Allow administrators to create and manage examinations.
- Allow administrators to create and manage multiple-choice questions.
- Allow students to securely attend examinations.
- Automatically evaluate submitted answers.
- Generate and display examination results.

## Technology Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Python / Django
- Database: SQLite (development) / PostgreSQL (if required)
